Deploy in 30 seconds

Publish a static folder from your terminal using Wrangler or Surge.

# Deploy to Cloudflare Pages (Unlimited Free Bandwidth)
npx wrangler pages project create my-homepage
npx wrangler pages deploy ./dist --project-name=my-homepage

# Or deploy via Surge.sh in one command
npx surge ./dist my-free-site.surge.sh
