Example is-a.dev JSON record

Add this file to domains/yourname.json in the registry repository.

{
  "owner": {
    "username": "your-github-username",
    "email": "you@example.com"
  },
  "records": {
    "CNAME": "your-github-username.github.io"
  }
}
