# Contributing to Free Web Hosting & Free Domains

Thank you for helping keep this directory of **free web hosting** and **free site domain name** providers accurate and up to date!

## Inclusion Criteria

1. **Genuinely Usable Free Tier or Verified Cloud Credit:** The provider must offer either a permanent free plan (static, PHP/MySQL, PaaS, VPS, database, or domain/subdomain) or a verified developer trial/cloud credit.
2. **No Forced Malware or Pop-Up Ads:** We strictly reject providers that inject intrusive pop-unders, crypto miners, or deceptive redirects onto user websites.
3. **Clear Technical Specs:** Every entry must list storage, bandwidth, runtime/DNS support, and custom domain / SSL availability.

## How to Submit a Pull Request

1. Fork [`free-website-domains/free-web-hosting`](https://github.com/free-website-domains/free-web-hosting).
2. Add your entry to the appropriate table in `README.md` (and optionally `providers.json`).
3. Verify formatting and run `python3 hosting_finder.py --category all` to test the JSON structure.
4. Open a Pull Request describing the provider's free tier limits and verification date.
